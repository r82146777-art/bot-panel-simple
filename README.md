# پنل ساده مدیریت ربات‌ها (تلگرام | روبیکا | بله)

یک پنل وب خیلی ساده برای مدیریت ربات‌های تلگرام، روبیکا و بله.

## ویژگی‌ها

- سه دکمه ایجاد ربات: **تلگرام**، **بله**، **روبیکا**
- فرم با ۳ کادر:
  1. توکن ربات
  2. آیدی عددی مالک / کانال
  3. کد ربات (منطق ربات)
- دکمه **تأیید و استارت**
- لیست ربات‌های ساخته‌شده با دکمه **ویرایش**
- رابط کاربری راست‌چین و فارسی

> **توجه مهم**: این پنل فقط برای مدیریت و تولید فایل ربات است.  
> چون سرور دائمی نداریم، ربات‌ها واقعاً ۲۴ ساعته اجرا نمی‌شوند مگر اینکه خودت پروژه را روی یک هاست رایگان (مثل Render یا Railway) دیپلوی کنی و از Process Manager استفاده کنی.

## نصب و اجرای محلی

```bash
git clone https://github.com/r82146777-art/bot-panel-simple.git
cd bot-panel-simple
pip install -r requirements.txt
python app.py
```

سپس برو به: [http://127.0.0.1:5000](http://127.0.0.1:5000)

## دیپلوی رایگان (پیشنهادی)

### روش ۱: Render.com (رایگان)
1. برو به [render.com](https://render.com) و با گیت‌هاب لاگین کن
2. New → Web Service
3. این ریپو را انتخاب کن
4. Build Command: `pip install -r requirements.txt`
5. Start Command: `gunicorn app:app`
6. دیپلوی کن

### روش ۲: Railway.app
1. برو به [railway.app](https://railway.app)
2. New Project → Deploy from GitHub
3. این ریپو را انتخاب کن
4. خودش تشخیص می‌دهد و اجرا می‌کند

## هشدار امنیتی

کد رباتی که در کادر سوم می‌نویسی، کد پایتون است.  
هرگز کد ناشناس یا مشکوک را در آن قرار نده. این پنل برای استفاده شخصی طراحی شده.

## ساختار پروژه

- `app.py` → بک‌اند Flask
- `templates/index.html` → رابط کاربری
- `bots.db` → دیتابیس SQLite (خودکار ساخته می‌شود)
- `generated/` → فایل‌های ربات تولیدشده
